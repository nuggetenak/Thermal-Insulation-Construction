# How this curriculum is structured

This document is intentionally a syllabus/TOC only — a learning-target map, not the lesson content itself. Each item is a target the content-generation phase (see companion Opus brief) expands into full modules: explanations, worked examples, diagrams, procedures, reference material.

This is a CONSOLIDATED version merged from two earlier drafts ("Master" and a shorter reference draft) plus direct cross-checking against the official 厚生労働省 (MHLW) 技能検定 exam-scope document for 熱絶縁施工. No chapters were removed; this pass closed structural gaps versus the source drafts (関係法規, corrosion-under-insulation, several material/support/fitting sub-types, a more accurate 技能検定 domain breakdown, a verified official-source appendix).

This revision also splits the whole document into PART 1 (Universal Craft Knowledge — build this first) and PART 2 (Japan-Specific Layer — vocabulary, workplace communication, certification/pathway — build this second). The one scattered Japan-specific block that lived inside a Part 1 chapter (site-behavior norms, formerly Ch01.4) has been relocated into Part 2 (now Ch24.6) so Part 1 is fully country-agnostic. See Appendix A for the resulting build sequence.

Progression: Foundation → Basic Field Skills → Core Insulation Work → Complex Details → Quality/Safety → Independent Work → Skill-Test Preparation → Advanced/Lead Worker.

The scope centers on 保温保冷工事作業 within 熱絶縁施工 (NOT 吹付け硬質ウレタンフォーム断熱工事作業, the spray-urethane track — a separate official work category, out of scope here). Japanese terminology is included because the target workplace is Japan.

# Appendix B — Official Scope Anchors (Verified)

**Governing certification:** 技能検定 熱絶縁施工 (national trade skill test), work category 保温保冷工事作業. Sister category 吹付け硬質ウレタンフォーム断熱工事作業 (spray urethane) is a separate track — out of scope for this platform.

**Grades:** 2級 and 1級 share one national MHLW exam-scope document. A 3級 also appears to exist for this trade (commonly prefecture-administered, often open to trainees without prior work experience, and reportedly usable to waive the usual work-experience requirement for 2級 entry) — confirm against the current-year prefectural announcement before treating as fixed content; it was not part of the national 1級/2級 scope document pulled for this research pass.

**学科試験 (written) — 4 subjects:** 熱絶縁 basics, 関係法規 (建築基準法／消防法／廃棄物処理法／オゾン層保護法／地球温暖化対策推進法／建設リサイクル法 — relevant parts only), 安全衛生 (incl. relevant 労働安全衛生法), plus ONE selected specialty track (イ保温保冷施工法, this platform's scope, or ロ吹付けウレタン, out of scope). Related standard: JIS A9501（保温保冷工事施工標準）.

**実技試験 (practical) — officially graded core, 保温保冷工事作業:**

- 材料の複雑な取付け及び充てん
- 補助材の取付け及びこてぬり
- 防湿材の取付け
- 外装仕上げ
- 保温保冷工事の段取り (1級 only, scored as a separate item)

Format: 製作等作業試験 on a real pipe+elbow test bench (~呼び径100A).

**Passing score:** 実技 ≥60/100, 学科 ≥65/100.

**Employment-pathway relevance:** 熱絶縁施工（保温保冷工事作業）is also an official 技能実習 (Technical Intern Training) occupation. 保温保冷 is explicitly named as one of the covered work types under 特定技能1号建設 → ライフライン・設備 category (alongside 配管, 電気通信, 電気工事等). Workers who satisfactorily complete 技能実習 2号 or 3号 in this occupation become exam-exempt when transitioning to 特定技能 ライフライン・設備.

Use the current-year official examination documents and the employer/site specifications as final authority — this appendix is a planning anchor, not a live syllabus substitute.
